# M3 in-game checklist / Checklist in gioco di M3

This is the owner's check of milestone M3 ([`docs/roadmap/M3-roster-nights.md`](../roadmap/M3-roster-nights.md), step M3-9) in the real WoW: Forever client. A session cannot run the game, so every item below is **not verified** until the owner ticks it. Keep the addon's English and Italian lines together: each item is written in English and then in Italian. The first check of M1 is in [`M1.md`](M1.md); this file starts where it ends and assumes M1 is ticked.

Questa è la verifica del proprietario della milestone M3 ([`docs/roadmap/M3-roster-nights.md`](../roadmap/M3-roster-nights.md), passo M3-9) nel client reale di WoW: Forever. Una sessione non può avviare il gioco, quindi ogni voce qui sotto è **non verificata** finché il proprietario non la spunta. Il primo controllo di M1 è in [`M1.md`](M1.md); questo file parte da dove finisce e presuppone M1 spuntata. Ogni voce è scritta in inglese e poi in italiano.

> Status / Stato: **checklist ready, owner run pending** / **checklist pronta, esecuzione del proprietario in attesa**.

> **Gap to know before you start / Limite da sapere prima di iniziare.** No window opens a season yet (the Settings window comes with M5 and M7-2), and the declarations of the pool come from the requests of M3-2 that no window sends yet. So every check that needs an **open season** (sections 2, 3, 4, 6 and the first-kill recording of 7) can only be run if a season is already in the ledger, for example from the test rig. Where a check needs a season and you have none, write `not tested` and say why. The checks that need no season are marked *(no season)*. / Nessuna finestra apre ancora una season (la finestra Impostazioni arriva con M5 e M7-2), e le dichiarazioni del pool arrivano dalle richieste di M3-2 che nessuna finestra ancora invia. Quindi ogni controllo che richiede una **season aperta** (sezioni 2, 3, 4, 6 e la registrazione della prima uccisione della 7) si può fare solo se una season è già nel registro, per esempio dal banco di test. Dove serve una season e non ce n'è una, annota `non provato` e il motivo. I controlli che non richiedono una season sono marcati *(senza season)*.

## 0. Before you start / Prima di iniziare

1. Run the offline checks from the repository root (they must be green). / Esegui i controlli offline dalla radice del repository (devono essere verdi):

   ```bash
   python -I -X utf8 tools/check_docs.py
   python -X utf8 Tests/run_tests.py
   ```

2. Install the addon for the game with a link (edits show after `/reload`). The WoW folder is the one that contains `_forever_`; it comes from `--wow` or from `tools/local.ini`. / Installa l'addon per il gioco con un collegamento (le modifiche si vedono dopo `/reload`). La cartella di WoW è quella che contiene `_forever_`; viene da `--wow` o da `tools/local.ini`:

   ```bash
   python -I -X utf8 tools/fetch_libs.py
   python -I -X utf8 tools/install_addon.py --wow "<WoW folder>" --link
   ```

3. You need **three characters** to run section 5 well: an officer (a rank with `raid.addonCheck` and `night.run`, by default the Guild Master or an officer), a second raider with the addon, and a third raider **without** the addon (or with it disabled in the add-on list). Two clients in the same raid are enough for sections 1 to 4; the third is needed for the addon check. / Ti servono **tre personaggi** per la sezione 5: un officer (un grado con `raid.addonCheck` e `night.run`, di default il Guild Master o un officer), un secondo raider con l'addon, e un terzo raider **senza** l'addon (o con l'addon disabilitato nella lista). Due client nello stesso raid bastano per le sezioni da 1 a 4; il terzo serve al controllo dell'addon.

4. Record every result in a note as `ok`, `fail`, `not tested` or `non provato`, with the build number from `/fdcp debug`. Never write character, guild or player names in the note: write "officer", "raider", "third raider". / Annota ogni risultato come `ok`, `fail`, `not tested` o `non provato`, con il numero di build di `/fdcp debug`. Non scrivere mai nomi di personaggi, di gilda o di giocatori nelle note: scrivi "officer", "raider", "terzo raider".
