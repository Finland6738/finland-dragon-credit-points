# M1 in-game checklist / Checklist in gioco di M1

This is the owner's check of milestone M1 ([`docs/roadmap/M1-foundations.md`](../roadmap/M1-foundations.md), step M1-8) in the real WoW: Forever client. A session cannot run the game, so every item below is **not verified** until the owner ticks it. Keep the addon's English and Italian lines together: each item is written in English and then in Italian.

Questa è la verifica del proprietario della milestone M1 ([`docs/roadmap/M1-foundations.md`](../roadmap/M1-foundations.md), passo M1-8) nel client reale di WoW: Forever. Una sessione non può avviare il gioco, quindi ogni voce qui sotto è **non verificata** finché il proprietario non la spunta. Ogni voce è scritta in inglese e poi in italiano.

> Status / Stato: **checklist ready, owner run pending** / **checklist pronta, esecuzione del proprietario in attesa**.

## 0. Before you start / Prima di iniziare

1. Run the offline checks from the repository root (they must be green). / Esegui i controlli offline dalla radice del repository (devono essere verdi):

   ```bash
   python -I -X utf8 tools/check_docs.py
   python -X utf8 Tests/run_tests.py
   ```

2. Install the addon for the game with a link (edits show after `/reload`). The WoW folder is the one that contains `_forever_`; it comes from `--wow` or from `tools/local.ini`. / Installa l'addon per il gioco con un collegamento (le modifiche si vedono dopo `/reload`). La cartella di WoW è quella che contiene `_forever_`; viene da `--wow` o da `tools/local.ini`:

   ```bash
   python -I -X utf8 tools/fetch_libs.py
   python -I -X utf8 tools/install_addon.py --wow "<WoW folder>" --link
   ```

3. Start the game, enable **Finland Dragon Credit Points** in the add-on list and log in. Keep the default error display on (or run `/console scriptErrors 1`). / Avvia il gioco, abilita **Finland Dragon Credit Points** nella lista degli addon ed entra. Lascia attiva la visualizzazione standard degli errori (o esegui `/console scriptErrors 1`).

Record every result in a note as `ok`, `fail` or `not tested`, with the build number from `/fdcp debug`. Never write character or guild names in the note. / Annota ogni risultato come `ok`, `fail` o `non provato`, con il numero di build di `/fdcp debug`. Non scrivere mai nomi di personaggi o di gilda nelle note.

## 7. Two clients / Due client (M1-6)

**Not testable in M1.** The transport can send and receive (`Net/Transport.lua`, `Transport:Send`), but no command or window sends a message until the session protocol of M3 (M3-1 and M4-1). The check of "two clients hearing each other" (the delivery of `RAID`, `GUILD` and `OFFICER` addon messages with the prefix `FDCP1`, and the echo counters of `/fdcp debug`) is therefore listed here and ticked during M4-1, when the first session message exists. Until then the owner records it as `not tested`. / **Non verificabile in M1.** Il trasporto sa inviare e ricevere (`Net/Transport.lua`, `Transport:Send`), ma nessun comando o finestra invia messaggi prima del protocollo di sessione di M3 (M3-1 e M4-1). Il controllo "due client che si sentono" (consegna dei messaggi addon `RAID`, `GUILD` e `OFFICER` con prefisso `FDCP1`, e i contatori di eco di `/fdcp debug`) è quindi elencato qui e si spunta in M4-1, quando esiste il primo messaggio di sessione. Fino ad allora il proprietario annota `non provato`.

Do not include names of characters or guild members. / Invia le note alla sessione (o apri una issue) con: il numero di build, l'output di `/fdcp debug`, l'elenco delle voci `fail` o `non provato` e gli screenshot della finestra nei due temi. Non includere nomi di personaggi o membri della gilda.

When every item in sections 1 to 6 is `ok`, the owner ticks the "in game" box of M1-8 in [`docs/roadmap/M1-foundations.md`](../roadmap/M1-foundations.md) and the `v0.1.0` changelog section is written. / Quando ogni voce delle sezioni da 1 a 6 è `ok`, il proprietario spunta la casella "in game" di M1-8 in [`docs/roadmap/M1-foundations.md`](../roadmap/M1-foundations.md) e si scrive la sezione `v0.1.0` del changelog.
