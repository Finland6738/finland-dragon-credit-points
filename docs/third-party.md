# Third-party material and licences

The addon is GPL-3.0 ([LICENSE](../LICENSE)). This page records where every font, picture and library that ships in the
package comes from and under which licence. It is the single place to update when one is added (M7-1).

## Fonts (`FinlandDragonCreditPoints/Media/Fonts/`)

| Family | Files | Licence | Notes |
|---|---|---|---|
| **Outfit** (The Outfit Project Authors) | `Outfit-Regular.ttf`, `Outfit-Medium.ttf`, `Outfit-SemiBold.ttf` | SIL Open Font License 1.1, text in `Outfit-OFL.txt` | Static instances cut from the variable font and reduced to the Latin subset by `tools/make_fonts.py`. No Reserved Font Name. |
| **JetBrains Mono** (The JetBrains Mono Project Authors) | `JetBrainsMono-Regular.ttf`, `JetBrainsMono-Medium.ttf` | SIL Open Font License 1.1, text in `JetBrainsMono-OFL.txt` | Same treatment. No Reserved Font Name. |
| **Orbitron** (Matt McInerney, The League of Moveable Type) | `Orbitron-Bold.ttf` | SIL Open Font License 1.1, text in `Orbitron-OFL.txt` | Declares the Reserved Font Name "Orbitron", so the file ships **whole and unmodified**. Used for the window title only, in capitals. |

The OFL allows bundling the fonts in software under any licence provided the fonts are not sold on their own, the licence
text accompanies them and a modified version does not reuse a Reserved Font Name. The community site's logo font
(Atomed) has no licence that allows redistribution and is **not** included ([ADR 0004](adr/0004-interface-style-of-the-community-site.md),
`docs/specs/ui-style.md` §4). `tools/check_addon.py` fails when a family's licence text is missing.

## Icons (`Media/icons.tga`)

The 40 icons of the sheet are **drawn for this addon** by `tools/make_media.py` from simple Pillow shapes (lines, arcs,
ellipses, polygons). No third-party artwork is copied or traced; they are covered by the addon's GPL-3.0. The names and the
order of the cells are mirrored in `UI/Assets.lua` (`Assets.icons`).

## Textures (`Media/*.tga`)

The rounded rectangles, rings, shadows, glows, pill, circle and radial fall-off are generated by `tools/make_media.py`
(white shapes the theme tints at run time). Nothing in them comes from outside the repository.

## The guild logo (`Media/logo_256.tga`, `logo_64.tga`)

Made from `assets/logo-source.webp`, the guild's own logo, supplied by the repository owner as the addon's emblem. The
GPL-3.0 of the code does not by itself grant a right to use the logo for another purpose.

## The NEBULA community logo (`Media/nebula_dark_256.tga`, `nebula_light_256.tga`, `assets/nebula-logo-*.png`)

The logo of the NEBULA community, in a dark-theme version (orange-magenta-purple swirl, white word) and a light-theme
version (blue-green swirl, black word), supplied by the repository owner and used with the permission of the community
owner. It is shown in the credits only: the Info page (dark art on the Nebula and Drago themes, light art on Aurora),
the README, the manual and the CurseForge page. The textures are made from `assets/nebula-logo-dark.png` and
`assets/nebula-logo-light.png` by `tools/make_media.py` without recolouring. As with the guild logo, the GPL-3.0 of the
code does not by itself grant a right to use it for another purpose.

## Game art

No Blizzard artwork is copied into the repository. The Progress tab shows the Encounter Journal's own image of a raid
when the client has it (read from the game at run time) and a generated cover otherwise.

## Libraries (`FinlandDragonCreditPoints/Libs/`, fetched at packaging time)

Ace3 (Release-r1403), LibDataBroker-1.1 (v1.1.4) and LibDBIcon-1.0 (v8.0.4) are embedded by the packager from the
versions pinned in `.pkgmeta`; each is a whole repository at a tag and keeps its own licence file inside its folder.
