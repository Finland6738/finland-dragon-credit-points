# Installation

> **Not available yet.** There is no download of Finland Dragon Credit Points yet: the addon is still being built. This page will explain how to install it once the first test version is published. [Italiano](Installation-it)

What it will cover:

- where to download the addon;
- copying the `FinlandDragonCreditPoints` folder into `<WoW folder>/_forever_/Interface/AddOns/`;
- enabling it in the AddOns list of the character screen;
- checking that it works with `/fdcp`.

Every raider needs the addon to roll: a raider without it cannot take part in the rolls.
