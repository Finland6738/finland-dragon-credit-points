# 0004. The interface follows the community site's style

- Status: Accepted
- Date: 2026-11-20 (owner's requirement of 2026-11-20, step M1-6b)

## Context

The analysis (`docs/ANALISI.md` §9, first version) planned a Material Design 3 interface in the colours of the guild logo, with a navigation rail. The owner then asked that the addon look like the guild community site's WoW Forever page, after an expert assessment of what the WoW client can reproduce. The site's theme is different from the logo's: violet-black, amber and magenta instead of green and gold. The client has no CSS; it only has textures, 9-slice, masks, bundled fonts and `AnimationGroup`. The site's display font (Atomed) carries "All Rights Reserved" metadata and no licence.

## Decision

- [`docs/specs/ui-style.md`](../specs/ui-style.md) is the reference for every window. It holds the tokens, the components, the in-game technique and a feasibility verdict for each element.
- Themes are token tables over the same names. **Nebula** (the site's dark theme) is the default; **Aurora** (the site's light theme) and **Drago** (the logo palette) can be chosen in Settings without `/reload`. The default is a setting, so it is reversible.
- The main window has six horizontal tabs like the site's: Roster · Credits · Progress · Loot · History · Settings. They replace the navigation rail.
- Fonts: Outfit and JetBrains Mono, as on the site, under SIL OFL 1.1, which allows bundling in a GPL-3.0 addon with `OFL.txt`. Orbitron (OFL 1.1) replaces Atomed, which is not redistributed. The game's fonts are the fallback.
- Every texture is white and tinted at runtime, so no file depends on a theme.
- The design previews are generated by `tools/make_mockups.py` and checked by `tools/check_docs.py`.

## Alternatives considered

- **Keep the logo palette as the default**: the addon would not look like the site the guild already uses.
- **Bundle Atomed**: there is no licence that allows redistribution.
- **Keep the navigation rail**: the site's members already know the tab bar.

## Consequences

M1-7 builds the theme from the spec. Every window step and M7-1 refer to it. The roadmap gains steps M3-3b (first kills) and M3-8b (Progress tab). Elements marked "not feasible" (backdrop blur, letter spacing, spring curves) use the alternatives listed in the spec. The in-game look stays unverified until the owner checks M1-7.
